# Software factory prototype: demo video

A ~5.2 minute (1920x1080, 30 fps) walkthrough of the "Software factory prototype plan" (Oct 2026).
None of the plan's 19 actions has started, so the video is a **simulated** walkthrough: every Jira,
terminal and GitHub screen is a stylized look-alike panel with generic styling, and a corner tag
reading "Prototype concept · simulated" stays on screen throughout. No real product logos are used.

**Audio.** The voiceover is synthesized offline with [Piper](https://github.com/rhasspy/piper)
using the `en_US-ryan-high` voice (male), one clip per sentence, normalized to about -16 LUFS with a
very light synthetic room. The music bed is generated in code by `make-music.py` (slow A-minor pad
chords, filtered noise texture, a faint 70 bpm pulse; royalty-free by construction), ducked under the
speech and mixed at about -29 LUFS. The full narration is in the sidecar `.srt`; the video shows
short key phrases instead of burned-in captions. If `src/audio-durations.js` is removed, the page
falls back to reading-pace timings with burned-in captions and no audio.

## Re-render

Requirements: Node 22+, the `playwright` package with Chromium (resolved locally or from
`npm root -g`), `ffmpeg` with libx264 and aac, `curl`, Python 3 with `numpy` and `piper-tts`
(`pip install piper-tts`), and the Piper voice files `voices/en-us-ryan-high.onnx` and
`voices/en-us-ryan-high.onnx.json` (gitignored; download them from the Piper voices release on
Hugging Face, `en/en_US/ryan/high`).

```bash
cd demo-video
./build.sh                                # everything: voice + music + mix, SRT + script.md, 30 fps video with audio
./build.sh --fps 2 --out out/draft.mp4    # same, as a fast low-fps draft
node render.mjs --stills 30,150,210 --stills-dir frames   # PNG stills for a quick look
```

`build.sh` runs `build-audio.py` (Piper clips are cached in `audio-cache/`, so re-runs are quick),
`build-text.mjs`, then `render.mjs --audio out/audio/mix.wav`. Measured levels are written to
`out/audio/levels.json`. The full render takes about 6 minutes on 4 CPUs, plus about 3.5 minutes
the first time the voice clips are synthesized.

On the first run `render.mjs` downloads Inter and JetBrains Mono into `src/fonts/` (gitignored).
If that fails, the page falls back to local sans and mono fonts.

Useful flags: `--fps`, `--from`/`--to` (seconds), `--workers` (parallel browser pages, default 3),
`--out`, `--audio`, `--tmp`.

To preview in a browser, serve `src/` and open `index.html?t=150` for one frame, or `index.html?play`
for real-time playback.

## Structure

| File | Purpose |
| --- | --- |
| `src/timeline.js` | Single source of truth: the narration text for each beat, its spoken form for the synthesizer, beat durations (measured voice length plus padding, with a per-beat minimum) and caption cues mapped onto the sentence timings. Used by the page and by the Node and Python scripts. |
| `src/audio-durations.js` | Generated by `build-audio.py`: measured clip length of every narration sentence. |
| `build-audio.py` | Piper synthesis per sentence, voice track and loudness normalization, music generation, ducking and the final mix. |
| `make-music.py` | Generates the ambient music bed (numpy synthesis). |
| `build.sh` | One-command rebuild. |
| `src/scenes.js` | Builds all scenes and exposes `window.seek(t)`, which sets every element's style as a pure function of `t`. Elements declare timing with `data-in` / `data-out` (for example `ticket#4:0.5` means 0.5 s after caption cue 4 of the `ticket` beat), so the visuals stay in sync with the captions. Also holds the terminal script, the 14-check checklist and the PR states. |
| `src/styles.css` | Dark theme, one accent colour. |
| `src/index.html` | Page shell: scenes container, corner tag, key-phrase or caption bar, progress bar. |
| `render.mjs` | Playwright frame capture (`seek(t)` then a screenshot per frame), piped as JPEG into ffmpeg in parallel segments, then concatenated losslessly with `+faststart`. Writes the SRT next to the MP4. |
| `build-text.mjs` | Generates `script.md` and the SRT from `src/timeline.js`. |
| `script.md` | The narration script with timings (generated; edit `src/timeline.js` instead). |

Nothing depends on wall-clock time, so any frame can be re-rendered on its own and renders are
deterministic.
